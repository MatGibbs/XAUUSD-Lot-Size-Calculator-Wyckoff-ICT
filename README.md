## ☑️ 2. The 7-Step Binary Execution Checklist (Wyckoff + ICT)

Before computing Step 7, all 6 structural conditions must return `TRUE`:

1. **HTF Structure (H4 / H1):** Directional bias mapped on Higher Timeframes.
2. **Liquidity Pools:** Resting orders mapped at Previous Day High/Low (`PDH`/`PDL`) and Asian Session extremes.
3. **Liquidity Sweep:** Wait for the institutional stop hunt (*Wyckoff Spring / UTAD*). Never chase early breakouts.
4. **Market Structure Shift:** Clean `CHOCH` / `BOS` confirmed with institutional Displacement.
5. **Unmitigated Zone:** Define the active Order Block (`OB`) or Fair Value Gap (`FVG`).
6. **Execution & Invalidation:** Enter on the Return to Order Block (`RTO` / *Wyckoff LPS*) with structural Stop Loss beyond the sweep wick.
7. **100-Oz Position Sizing:** Calculate exact lot size based on Pip distance.
